## Bloco de Notas com SQLite
Esta é apenas uma atividade que fiz em casa para unir o que estou aprendendo nas disciplinas de Laboratório de Programação (Python) e Banco de Dados I (SQL). A ideia foi criar um bloco de notas simples que roda no terminal.

### O que o programa faz:

1. Salva o texto que você digita direto no banco de dados (`INSERT`).
2. Ele lê a tabela e lista todas as anotações salvas com seus respectivos IDs (`SELECT`).
3. Também apaga uma linha do banco com base no número do ID que o usuário escolher (`DELETE WHERE`).
4. E, se o usuário quiser, apaga todos os registros de uma vez só se o usuário confirmar.

### (?) Como rodar:

Se quiser testar o script:
1. Copie o arquivo `bloco_de_notas.py` para o seu computador.
2. Execute no terminal ou prompt de comando:
   'python bloco_de_notas.py'
