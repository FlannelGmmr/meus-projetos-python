# Atividades da Faculdade
Repositório destinado ao armazenamento de exercícios e pequenos projetos desenvolvidos durante a graduação em Sistemas de Informação.
## Projetos
### Gerenciador de Tarefas
Aplicação desenvolvida em Python para gerenciamento simples de tarefas acadêmicas por meio do terminal.
O programa permite:
* Adicionar tarefas;
* Listar tarefas cadastradas;
* Marcar tarefas como concluídas;
* Remover tarefas;
* Identificar cada tarefa por um ID.

### Bloco de Notas com SQLite
Aplicação desenvolvida em Python utilizando SQLite para armazenar anotações.
O programa permite:
* Inserir anotações no banco de dados;
* Listar as anotações cadastradas;
* Remover uma anotação pelo ID;
* Remover todos os registros mediante confirmação.
## Execução
Os arquivos Python podem ser executados utilizando o Python 3:
```bash
python nome_do_arquivo.py
```
Os notebooks podem ser abertos diretamente no Google Colab.
## Tecnologias
* Python
* SQLite
* Google Colab
* Jupyter Notebook

Reunir exercícios e projetos desenvolvidos durante a graduação para fins de estudo, prática e acompanhamento da evolução na programação e em banco de dados.
